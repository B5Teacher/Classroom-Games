Some, Any, or a Number?

Drag a word from the bank into each blank

some — statements and offers ("I have some money." / "Would you like some coffee?")

any — negatives and most questions ("I don't have any money." / "Do you have any money?")

a number — a new number is picked each round. Any number works; the skill is knowing the sentence needs a number.

The bank has 3 words — some, any, and this round's number — and you can drag out as many copies as you need. Five sentences are on screen at a time; solve one and a new one takes its place. Finish the round and all the sentences are shown so you can write them down.
